# LP Emergent Example — Workshop Kayu Purworejo

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

**Contoh edukatif** landing page properti/bisnis yang dibangun dengan [Emergent.sh](https://emergent.sh). Dibuat sebagai referensi teknis open-source menggunakan React + Tailwind CSS.

> ⚠️ **Template Edukasi** — Ganti semua placeholder (`YOUR_WHATSAPP_NUMBER`, alamat, deskripsi properti, harga) dengan data bisnis kamu sendiri sebelum deploy.

---

## Tentang Proyek Ini

Demonstrasi cara membangun landing page properti/bisnis lokal menggunakan Emergent.sh agent. Stack:

- React 18 + JavaScript
- Tailwind CSS
- SEO-optimized (meta tags, JSON-LD structured data)
- Mobile-first responsive design

---

## Cara Pakai sebagai Template

1. **Fork** atau clone repo ini
2. **Edit** `frontend/src/App.js`:
   - Ganti `YOUR_WHATSAPP_NUMBER` dengan nomor WA kamu (format: `628xx`)
   - Update nama bisnis, deskripsi, harga, alamat, koordinat peta
3. **Update** `frontend/index.html` meta tags (title, description, og:image)
4. **Deploy** ke Netlify / Vercel / Cloudflare Pages

---

## Quick Start

```bash
git clone https://github.com/alfindigital/lp-emergent-ex-kriyaworks.git
cd lp-emergent-ex-kriyaworks/frontend
npm install
npm run start    # dev server
npm run build    # production
```
